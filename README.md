A responsive personal portfolio built with HTML, CSS, and JavaScript and designed to deploy directly with GitHub Pages.

- **BotiCard** — QR-based medicine distribution and inventory system
- **Blooms Flower Shop** — academic e-commerce project
- **MarsKape** — responsive coffee shop website

## Achievement

- **2nd Place — Arduino Competition**, Cavite State University – Trece Martires City Campus, January 24, 2025

## Before publishing

Open `index.html` and replace:

```html
YOUR_EMAIL@example.com
```

with your professional email address.

You can also add a resume PDF later and change the hero or navigation link to point to it.

## GitHub Pages deployment

For the clean URL `https://katapostol.github.io`, create a repository named:

```text
KatApostol.github.io
```

Then upload/push all files from this folder so `index.html` is in the repository root.

In GitHub:

1. Repository → **Settings**
2. **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/(root)**
6. Save
